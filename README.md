# 语燕输入法（语音增强定制版）

本仓库是 [gurecn/YuyanIme（原版语燕输入法）](https://github.com/gurecn/YuyanIme) 的定制分支：以原版为基础，集成**外部语音识别（说点啥 / BiDi）**与**可配置热词替换引擎**，并修复多项真机反馈问题。代码已反子模块化（`yuyansdk` 直接内嵌），克隆后开箱即用。

---

## 一、本版新增特性（相对原版）

### 1. 语音识别 A / 语音识别 B（双按钮）
- 功能栏提供两个独立语音入口，可分别配置**点按**或**长按**录音：
  - 点按（tap）：点一下开始录音、再点一下结束；
  - 长按（hold）：按住录音、松开结束。
- 录音中对应按钮图标**变红**提示（点击瞬间即点亮，不依赖识别引擎回调）。
- 按钮开关、交互方式可在设置页调整。

### 2. 外部语音识别引擎（说点啥 BiDi 联动）
- 通过系统输入法 + 后台识别服务架构，无需在应用内集成 SDK：
  - 手机先安装 **[说点啥](https://www.brycewg.cn)（BiDi）**，在其设置中开启 **“对外接口 / 外部联动”** 并配置 ASR 识别引擎（推荐火山引擎）；
  - 语燕输入法启动后**持续绑定**说点啥识别服务（IME 存活期间不解绑），说点啥退到后台也不会因进程被杀而失联；连接断开后 2 秒内自动重绑。
- 识别结果自动上屏。

### 3. 热词替换引擎（新语法 + 旧式兼容）
- 配置文件驱动，全部放在手机公共目录 `Documents/YuyanVoice/`（**首次使用自动创建**，含默认配置、示例词库与说明文档 `README.md`）。
- `voice_config.txt` 主配置：总开关、交互方式、发音相似度阈值、应用顺序、启用词库列表、**强制纳入词库列表**（`include_wordbooks`：名称与文件夹内 TXT 文件名匹配即加载，忽略大小写，不受启用列表过滤）；含 `config_version` 版本字段——程序升级后配置不匹配时**自动备份旧配置（voice_config.v旧版本号.bak）并重建默认配置**，同时提示到设置页重新勾选生效词库。
- `wordbook_*.txt` 词库文件（**单文件内用 `[[词库名]]` 划分多个词库**，名称任意；可选用 `[regex]` / `[hotword]` 段标记强制类型）：
  - 分段从上到下：`[[词库一]]` 与 `[[词库二]]` 之间的规则属于词库一，末尾规则属于最后一个词库；
  - **新语法（手册 v1.0，无 `=` 号的行）**：
    `目标词 | 匹配词1 | 匹配词2 [~~~ 局部黑名单] [! 全文黑名单] [+ 全文白名单] [条件词X:替换词A1]`
    第一项为替换结果，其余为匹配词（命中任一个即替换）；`~~~` 局部黑名单（命中位置 ±5 字符内出现则不改）、`!` 全文黑名单（整句出现则整条不生效）、`+` 全文白名单（整句必须含其一）、`[条件词:替换词]` 条件块（整句含条件词时改用该替换词，首个命中生效，可多个）；
  - **旧式兼容**：含 `=` 的行仍按原版语法解析（`规范词 = 别名1 | 别名2`、`pattern = 替换`、行尾/行首 `!词|词` `+词|词` 修饰符、`~~~` 全文黑名单），旧词库文件无需改动即可使用；
  - 每个 `[[词库名]]` 都是一个独立词库，替换前会检查它是否启用。
- **热词库设置页**：设置 → 输入法 → 热词库设置，**每个 `[[词库名]]` 列成一行可单独勾选**（不勾选即跳过该词库全部词汇）、一键创建默认目录、一键**重启程序**应用新规则。
- 修改规则后无需重装：设置页点「重启程序」即可。

### 4. 原版问题修复
- **返回手势/返回键失效**（原版第一版即存在，Android 13+ 部分环境复现）：原版在视图层无条件吞掉 `KEYCODE_BACK`，且 `ImeService.onKeyDown/onKeyUp` 的 `super` 调用写反，导致返回动画正常但页面不返回。已改为交给框架默认处理（键盘显示→收键盘，未显示→放行给应用执行返回）。
- **IME 窗口触摸区域**：非悬浮模式改用系统标准 `TOUCHABLE_INSETS_VISIBLE`，键盘以外区域不再被输入法窗口拦截。
- **键盘唤起即闪退**：`onComputeInsets` 在输入视图创建前访问未初始化视图导致 NPE，已全部加保护。
- **说点啥退后台后只能识别一次**：会话自愈三件套（启动前强制取消残留会话、60 秒看门狗自动复位、死连接自动重绑）+ 持续绑定。

## 二、与原版的差异速览

| 维度 | 原版 gurecn/YuyanIme | 本版 |
|---|---|---|
| 语音识别 | 内置方案，无外部识别接入 | 功能栏语音识别 A/B 双按钮，联动说点啥后台服务 |
| 热词库 | 无 | 新语法（目标词\|匹配词 + 黑白名单 + 条件块，旧式兼容），文件驱动 |
| 词库目录 | 无 | `Documents/YuyanVoice/`，自动创建 + 自动生成说明 README |
| 返回手势 | 部分设备失效（吞 BACK） | 已修复，交还框架处理 |
| 说点啥退后台 | — | 持续绑定 + 断连自动重绑 + 会话看门狗 |
| 模块结构 | `yuyansdk` 子模块（需 submodule update） | 已内嵌，克隆即用 |
| 签名 | 需自行生成 | 仓库自带演示签名（见构建说明） |

## 三、使用前准备

1. **安装说点啥**并开启“对外接口 / 外部联动”，配置 ASR 引擎（推荐火山引擎）；
2. **授予存储权限**（Android 11+）：系统设置 → 应用 → 语燕输入法 → “所有文件访问”，否则无法读写 `Documents/YuyanVoice/`；
3. 系统设置 → 语言与输入法 → 选择“语燕输入法”为当前输入法；
4. 功能栏点击「语音识别 A/B」开始使用；词库规则写在手机 `Documents/YuyanVoice/` 下。

> 配置文件格式、规则写法与示例详见手机 `Documents/YuyanVoice/README.md`（自动生成）。

## 四、构建

### 环境
- JDK 17（本项目验证：OpenJDK 17.0.11）
- Android SDK：compileSdk 36 / minSdk 23（build-tools 36.0.0）
- Gradle 8.9（wrapper 已指向国内镜像，构建脚本已配置阿里云 Maven 镜像）

### 命令
```sh
git clone <本仓库地址>
cd YuyanIme
# Windows: gradlew.bat :app:assembleDebug
./gradlew :app:assembleDebug
```
产物：`app/build/outputs/apk/offline/debug/yuyanIme_*.apk`

### 签名
仓库自带 `keystore/yuyan.jks` 与 `keystore.properties`（仅演示/自用，正式分发请自行替换），克隆后可直接出包。

## 五、原版功能（本版完整保留）

- Rime 引擎：全拼（九宫/全键）、双拼（小鹤/智能ABC/自然码/紫光/微软/搜狗/乱序17）、手写、五笔画；简拼、全拼；
- 英文智能输入、词库拓展（雾凇/白霜等）、符号/颜文字/EMOJI/微信特效表情；
- 单手键盘、悬浮键盘、键盘数字行、深色主题、自定义菜单栏与主题、剪切板、常用语；
- 全面屏键盘优化、隐藏输入法图标等。

## 六、已知说明

- 语音识别依赖说点啥处于可用状态（其后台麦克风采集受系统限制时，识别可能失败——这是系统级约束，非本应用可控）；
- 部分小米机型键盘菜单跳转设置需手动开启“后台弹出界面”权限（原版已知问题，同样适用）。
